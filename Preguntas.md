# Entrega de la páctica 0

Responde por escrito,con tus palabras:

1. ¿Qué diferencia hay entre preparar un archivo y confirmarlo?
Que para preparar se seleccionan los archivos que quieres incluir y para confirmar tienes que guardar esos pasos en el historial

2. ¿Cuándo puedes usar Descartar cambios y qué riesgo tiene?
Cuando quieres elimnar modificaciones que has realizado y volver a la última versión guardad

3. ¿Qué pasa con tu trabajo cuando cambias de una rama a otra?
   Que Git se va actualizando para mostrar la rama que has seleccionado

4. ¿Por qué no hubo conflicto al fusionar rama-a pero sí al fusionar rama-b?
Porque con la rama-a Git combinó los cambios automáticamente, pero en la rama-b Git no podía hacer lo mismo que en la rama-a

5. ¿Para qué sirve crear una rama de experimento, aunque luego se borre?
Para probar nuevas ideas o experimentar sin que la rama principal se modifique

6. Si descubres hoy un error cometido hace cinco commits, ¿qué haces para arreglarlo?
Lo que hay que hacer es corregir el error, y no es necesario borrar los cinco commits anteriores
